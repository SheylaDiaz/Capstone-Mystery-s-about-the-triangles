Mysteries about the triangles.

My project is about the mystery's about the triangles around the world. I focus on facts and information in my first page and on a missing people chart with a img display in my second page.
I wanted to shine light on all the triangles they are i was under the impression it was only the bermuda triangle but i found out i was really wrong and they are 12+ but i focus on that ones the had more info out there.

Getting unsplash key:

Sign up for an unsplash account 
(https://unsplash.com/) when you succesfully ceated your account go over to the left where the 3 lines and click product when it drops down click developers/Api  then go to Your apps next go to new application and fill in all the info necesary when you have completed that you can scroll all the way down until you see access key and that will be you api key for you to use in .env.

Installation:

install node.js
Run git clone https://github.com/SheylaDiaz/Capstone-Mystery-s-about-the-triangles.git in the terminal.
create a .env file at the root.
CD into the cloned directory.
Run npm install to install required packages
To start the development server, run-( npm run dev ) 
In your browser, go to http://localhost:8080
